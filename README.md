# Дракончик

Браузерная игра-раннер по мотивам офлайн-игры Chrome. HTML5 Canvas + TypeScript, без игровых движков и бэкенда.

## Запуск

Нужен Node 22+.

```bash
npm install
npm run dev
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер Vite |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run preview` | Локальный просмотр собранной версии |
| `npm run typecheck` | Проверка типов |
| `npm run lint` | ESLint |
| `npm test` | Юнит-тесты (Vitest) |

## Структура

- `src/config.ts` - размеры мира, цвета, палитра спрайтов, весь баланс игры
- `src/main.ts` - сборка: canvas, ввод, игра, цикл
- `src/core/` - игровой цикл с фиксированным шагом, ввод (клавиатура, тач, мышь), пул объектов
- `src/game/` - состояния игры, дракончик, кактусы и спавнер, коллизии, облака и декор
- `src/render/` - вьюпорт, пиксельные матрицы спрайтов, спрайт-лист, отрисовка
- `tests/` - юнит-тесты чистой логики

## Управление

- Пробел или стрелка вверх - прыжок (дольше держишь - выше), стрелка вниз - присед, в воздухе - быстрое падение.
- Тач: касание - прыжок, свайп вниз - присед. Рестарт - пробел, Enter, касание или клик по иконке.
- При смене вкладки или потере фокуса игра встает на паузу.

## Отступление от ТЗ

ТЗ требует монохромный пиксель-арт и смену дня и ночи через инверсию цветов. Небо сделано синим, поэтому палитра цветная, а инверсия дала бы оранжевое небо. Смена дня и ночи на следующем этапе будет плавной интерполяцией между дневной и ночной палитрой из `src/config.ts`, а не инверсией.
